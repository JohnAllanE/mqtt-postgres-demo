Million-point Persistence Lab

Create the same deterministic MQTT sensor stream in three isolated table designs. One million points produces 100,000 raw message rows, 1,000,000 normalized sample rows, and 200,000 grouped-array rows. This does not change the live demo data above.

How to choose

Seed the database to measure storage, then run the comparison to see which design fits each query workload.

Raw MQTT JSONB
—
One row per MQTT message; preserves the original payload.
Best fit: exact payload replay, audits, and evolving message schemas.
Normalized samples
—
One row per sensor reading; simplest indexed sensor queries.
Best fit: independent sensor queries, relational joins, and per-reading constraints.
Grouped arrays
—
Two equipment-group rows per message; compact and compatible with the live demo.
Best fit: fixed equipment groups, compact storage, and whole-group reads.
