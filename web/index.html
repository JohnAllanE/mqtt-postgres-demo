Sensor Live View

This page provides live and logged views for the simulated sensors, MQTT payloads, and the PostgreSQL array snapshot used by this demo.

Sensor live view — this is a direct WebSocket feed from the simulated sensors, provided for immediate context.

Logged Sensor Values

The polling interval sets how often the gateway sends data for ingestion into the PostgreSQL database. Use the "Reset DB" button to remove old values. If you change the polling interval, click "Apply Config" to send the update to the simulated gateway via an MQTT configuration message. The charts below display data plotted from the database (after ingestion) and are clustered into two equipment types.

Logged — group-6 (6 sensors)
Logged — group-4 (4 sensors)

Maintenance Mode

The higher-frequency maintenance plot shows values received over MQTT without committing them to the database. Specify sensor IDs (0-based) to request maintenance samples from the gateway; those IDs are sent as an MQTT configuration message.
